# IMAGE FORGE

ブラウザだけで画像のリサイズ・形式変換を行う、小さな画像ツールです。

**Web版**  
https://raika-rei-lab.github.io/image-forge/

## できること

- PNG / JPEG / WebP の読み込み
- WebP / JPEG / PNG への変換
- 画像サイズの変更
- Cover / Contain / Stretch の切り替え
- 複数画像の一括変換
- 用途別プリセット
- Raika & Rei Journal 用の安全範囲ガイド

## プリセット

- **Raika & Rei Journal** — 2400×1350 / 16:9 / WebP
- **note サムネ** — 1280×670
- **WordPress 汎用ワイド** — 1200×675
- **OGP / SNS** — 1200×630
- **正方形** — 1080×1080
- **Web軽量** — 長辺1600px

## Privacy

画像処理はブラウザ内で行います。  
選択した画像を外部サーバーへアップロードする処理はありません。

## 使い方

1. 画像をドラッグ＆ドロップ、または選択
2. プリセットを選ぶ
3. 必要ならサイズ・形式・品質を調整
4. 「全部変換して保存」を押す
